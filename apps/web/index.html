01 · Concept

MCP הוא הגשר בין ה-AI לבין הכלים המקומיים

המודל לא מקבל גישה קסומה למחשב. ה-Host — למשל Claude Desktop, Cursor או VS Code — מפעיל שרת MCP מקומי. השרת חושף כלים מוגדרים וברורים, והמודל מבקש להפעיל אותם דרך stdio.

    03 · Tool surface

    מה ה-AI מקבל בפועל

    כל פעולה היא Tool עם שם ברור, במקום פקודת execute כללית.

    Browser MCP

    browser_launchפותח Chrome אמיתי בחלון גלוי.
    browser_navigateניווט ל-URL.
    browser_clickלחיצה לפי locator או קואורדינטות.
    browser_typeהקלדה לשדה.
    browser_pressמקשים וקיצורי מקלדת.
    browser_page_textקריאת טקסט גלוי מהעמוד.
    browser_screenshotצילום viewport.
    browser_start_live_viewViewer מקומי עם WebSocket.

    Computer MCP

    computer_screenshotצילום המסך הראשי.
    computer_move_mouseהזזת העכבר.
    computer_clickלחיצה שמאלית/ימנית/אמצעית.
    computer_drag_mouseDrag לתוכנות גרפיות ותלת-ממד.
    computer_type_textהקלדת Unicode כולל עברית.
    computer_press_keyמקשים בודדים וחזרות.
    computer_hotkeyקיצורים כמו Ctrl+Shift+P.
    computer_scrollגלילה אנכית.
    04 · Safety

    שליטה מלאה צריכה להיות מקומית, מפורשת וניתנת לעצירה

    Local only

    שני שרתי ה-MCP משתמשים ב-stdio. אין endpoint ציבורי לפקודות שליטה.

    Permission gates

    Computer Control דורש הרשאות מפורשות לצילום מסך ולפעולות.

    Fail-safe

    PyAutoGUI שומר מנגנון עצירה באמצעות הפינה השמאלית-עליונה.

    Isolated Chrome

    Chrome משתמש בפרופיל MCP נפרד כברירת מחדל.

    06 · FAQ

    שאלות לפני שמתחילים

    האם ה-AI יכול לעבוד ב-Blender או Fusion 360?

    כן, ברמת מסך וקלט: צילום מסך → ניתוח → עכבר/מקלדת → צילום חוזר. לדיוק גבוה יותר אפשר לשלב API או MCP ייעודי של התוכנה.

    האם המשתמש יכול להזיז את העכבר בזמן שה-AI עובד?

    כן. אין נעילת input, ולכן אפשר להתערב בכל רגע.

    למה Chrome משתמש בפרופיל נפרד?

    כדי לצמצם חשיפה לעוגיות, sessions ונתונים אישיים מהדפדפן היומיומי.

    אילו סוגי AI נתמכים?

    האתר כולל GPT / ChatGPT, Codex, Claude Desktop, Cursor, VS Code, Windsurf, Cline ומצב AI בטרמינל. במצב טרמינל נחשף רק Computer Control MCP; בשאר הלקוחות המקומיים אפשר לחבר את שני השרתים.
